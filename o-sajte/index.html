О сайте

IG-2020 собирает системные требования компьютерных игр. На странице игры есть таблица с минимальными требованиями. Вторая таблица, с рекомендуемыми, есть только у тех игр, где издатель их опубликовал. Под таблицами коротко написано, какой процессор, видеокарта, память и диск указаны для этой игры.

Сайт не проверяет компьютер и не предлагает для этого программу. В таблицах стоят требования, которые указал издатель.

Игры собраны в каталоге. Отдельно есть подборки для слабого ПК, для ноутбука и самых требовательных игр. В гайдах разобраны память, диск и чтение таблицы требований.

Чем полезен каталог

  • можно сравнить минимальные и рекомендуемые требования одной игры;
  • можно посмотреть, сколько нужно оперативной памяти и что написано про диск;
  • можно открыть похожие игры и подборки.

Нужна ли программа для проверки компьютера?

Сайт показывает требования, но сам компьютер не проверяет. Отдельная программа для Windows могла бы посмотреть процессор, видеокарту и память и сказать, подходят ли они для выбранной игры.

Если за такую программу проголосует больше 1000 человек, сделаем её.
